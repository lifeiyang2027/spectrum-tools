# spectrum-tools

光谱仪测试数据的解析与汇总工具。用 Python 把仪器导出的原始文件整理成可复核的统计表。

> 仓库内所有示例数据均为程序生成的模拟数据，不含任何真实测试记录、企业参数或内部型号。

## 要解决的问题

做光谱类测试时，仪器每测完一次导出一个文件，一天几十个。手工抄进 Excel 既慢又容易错位。这个仓库做的是把重复劳动自动化：文件进来，统计表出去。

## 计划内容

### 1. 光谱数据汇总器

输入仪器导出的文本/CSV，输出一份多 sheet 的 Excel：

- **统计表**：逐文件算平均值、极值及其位置、平坦度、若干定点波长的取值
- **明细表**：逐波长点展开，便于回查原始数据
- **累计表**：多次运行的汇总结果按文件指纹去重后追加，用于看长期趋势

关键约定：原始文件里仪器已算好的指标只读取、不重算，避免引入算法偏差。

### 2. 仪器模拟采集

在没有真实仪器可接时，用模拟后端替代，跑通「主机 → 仪器 → 数据 → 表格」整条链路。

目的是掌握 PyVISA 的调用方式和 SCPI 指令的书写格式，这套东西换任何品牌的仪器都通用。

### 3. 数据格式解析

解析一种带二进制文件头 + 数据块的科研数据格式，取出点阵并绘图验证解析是否正确。

## 目录结构

│  ├─ export_excel.py       # 输出 Excel
│  └─ visa_demo.py          # 仪器模拟采集
├─ data/

├─ tests/                   # pytest 用例
├─ output/                  # 运行产物，不入库
├─ requirements.txt
└─ README.md
```

```
